# Principles

What Kalve 137 aims for. Base-layer design choices are checked against these, so the base never blocks one of them.

- Local first, always. Projects are folders and designs are files you own. Everything works offline, with no account, no sign-in and no sync. Nothing may assume a network.
- Minimal and clear. A small, focused feature set where each tool does one job and common tasks have one obvious way. A feature has to earn its place.
- Polish over breadth. Fewer tools that feel finished: live previews, sensible defaults, clear errors, fast startup.
- Intuitive defaults. Simple problems get simple solutions. If a basic task takes several dialogs, the design is wrong.
